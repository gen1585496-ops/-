# ヒビシール

毎日の日記を書くとステッカーが1枚もらえる。獲得したステッカーはそのままカレンダーの記録できた日に貼られ、書きためた日記から思考の傾向を振り返れるスマートフォンアプリ（企画・MVP開発中）。

企画の詳細（コンセプト、画面構成、技術構成、ロードマップなど）は別途共有した企画書を参照してください。

## 現在の実装状況（Phase 1: MVP）

`mobile/` に Expo (React Native + TypeScript) アプリを実装しています。

- 今日の日記を書いて保存する（テキスト＋気分選択）
- 保存すると、その日のカレンダーのマスにステッカーが自動で貼られる
- 連続記録日数（3日／7日／30日／100日）でレアなステッカーを獲得
- カレンダーの日付をタップすると、その日の日記を見返せる

データは端末内（AsyncStorage）にのみ保存され、外部送信は行いません。

## 開発環境の起動

```bash
cd mobile
npm install
npm run android   # Android（エミュレータ／実機）
npm run ios       # iOS（macOSのみ）
npm run web       # ブラウザでのプレビュー
```

Android実機・エミュレータで動作確認する場合は [Expo Go](https://expo.dev/go) を使うか、`npm run android` で Android Studio のエミュレータに接続してください。
